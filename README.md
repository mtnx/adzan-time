# Waktu Sholat Widget

Widget home screen Android: sholat berikutnya, hitungan mundur live, dan 5 waktu sholat.
Data dari https://api.aladhan.com (method=20, Kemenag RI), disimpan per bulan sehingga tetap jalan offline.

## Build tanpa Android Studio
1. Buat repo GitHub, upload semua isi folder ini (termasuk folder .github).
2. Buka tab Actions, tunggu workflow "Build APK" selesai (sekitar 3-5 menit).
3. Download artifact "waktu-sholat-apk", extract, install app-debug.apk.
4. Buka app, pilih GPS / kota, lalu tahan layar home dan tambahkan widget "Waktu Sholat".
